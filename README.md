# Algoritmos-de-ordenacao-em-C
Projeto desenvolvido para composição de nota da matéria Algoritmos e Pensamento Computacional. Tem como principal Objetivo explorar as diversas maneiras de ordenação utilizando a linguagem C.
## Sobre o Projeto:
O projeto foi criado com intenção de implementar 4 tipos de ordenação a um programa e observar o desempenho de cada um e como seu desempenho varia conforme o tamanho do vetor.

## Algoritmos Implementados

- Bubble Sort
- Insertion Sort
- Selection Sort
-  Quick Sort 
- Merge Sort

## Como o Programa opera
- é inserido um arquivo de texto contendo números desordenados, como por exemplo: "Dados.txt".

- é exibido uma tela que permite a escolha do algoritmo que o usuário deseja utilizar.

- A partir das informações selecionadas o programa reorganiza em ordem crescente as númerações.

- Após isso, ele gera um arquivo adicional com os dados reorganizados.
